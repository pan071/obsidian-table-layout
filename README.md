# Obsidian 表格列宽、对齐与铺满布局

# 1、功能概览

- 在实时预览和阅读视图中调整 Markdown 表格的列宽、对齐方式和页面位置。
- 所有样式保存在插件数据（`.obsidian/plugins/table-layout/data.json`）中，**不改动笔记原文**。
- 仅支持桌面端；源码模式下不生效。

# 2、列宽

- **默认铺满：** 未调整过列宽的表格自动撑满页面宽度，可在设置中关闭。
- **拖动列边框：** 鼠标移到两列之间的边框上，光标变为左右箭头后拖动。
    - 普通拖动：与右侧相邻列互相让出宽度，表格总宽不变，调整后仍然铺满页面。
    - 拖动最后一列的右边框，或按住 `Shift` 拖动任意列：只改当前列，表格总宽随之变化。
        - 拉宽超过页面时出现横向滚动条。
        - 缩窄到页面宽度以下时，按「表格位置」居左/居中/居右显示。
        - 总宽与页面宽度相差 8px 以内时自动吸附为铺满。
- **双击列边框：** 该列按最长内容自适应宽度，上限见设置「自适应列宽上限」。
    - 铺满状态下，其余列按原比例分摊剩余宽度；剩余宽度不够时转为超宽。

# 3、右键菜单

- 右键表格单元格 →「表格布局」，菜单项追加在 Obsidian 自带的表格菜单中。
- **对齐：** 选择作用范围后设置水平（左/居中/右）与垂直（顶端/居中/底端）对齐，或清除对齐。
    - 作用范围：当前单元格、当前行、当前列、整个表格。
    - 实时预览中先用 Obsidian 自带的行/列手柄或拖选选中单元格，再右键选区，会多出「选中区域」：选中整行按行设置、选中整列按列设置，其他按单元格逐个设置。
    - 右键行/列拖动手柄时，直接提供「当前行」或「当前列」。
    - 同一单元格命中多条规则时，最后设置的生效。
- **表格位置：** 居左、居中、居右，仅在表格窄于页面时生效。
- **列宽：** 铺满页面宽度（保持当前列宽比例）、整表按内容自适应、当前列按内容自适应。
- **重置：** 恢复默认列宽、清除本表全部样式。

# 4、命令

- 「当前表格铺满页面宽度」「当前表格按内容自适应列宽」「当前表格恢复默认列宽」，作用于实时预览中光标所在的表格，可在「设置 → 快捷键」中绑定。

# 5、样式与表格的对应规则

- 样式按「文件路径 + 文件内第几个表格」保存，同时记录表头和每行首个单元格的原文。
    - 在表格上方新增或删除其他表格：按表头重新找回对应样式。
    - 增删列、调整列顺序：按表头文字重新对应列宽与列对齐，新增列取平均列宽。
    - 增删行：按每行首个单元格的文字重新对应行与单元格对齐。
- 文件重命名、移动时样式跟随迁移，删除文件时一并清理。
- **已知限制：**
    - Callout、引用块中的表格不处理。
    - 样式不写入笔记，换设备时需同步 `data.json` 才能保留。
    - 表头文字与列数同时大幅改动时，可能无法找回原样式。

# 6、构建与安装

- 安装依赖：`npm install`
- 构建并安装到仓库：`npm run deploy`，默认仓库为 `/path/to/vault`，可通过环境变量 `OBSIDIAN_VAULT` 覆盖。
- 安装后在「设置 → 第三方插件」中启用「Table Layout」。
